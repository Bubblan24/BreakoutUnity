# Breakout-Unity

A classic brick-breaking arcade game built with Unity and C#.

## Overview

Control a paddle to bounce a ball and destroy bricks. Keep the ball in play and clear the level to progress through the game.

## Features

- Paddle movement
- Ball physics and bouncing
- Brick destruction
- Collision detection
- Score tracking
- Level completion mechanics

## Built With

- **Engine:** Unity
- **Language:** C#
- **Version Control:** Git and GitHub

## Getting Started

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the project folder.
4. Open the project using a compatible Unity version.
5. Open the main scene and press **Play**.

## Project Structure

- `Assets/` — Game assets, scripts, and scenes
- `Packages/` — Unity package dependencies
- `ProjectSettings/` — Unity project configuration
